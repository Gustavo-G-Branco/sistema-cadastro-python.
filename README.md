# Sistema de Cadastro e Gerenciamento em Python

## Sobre o Projeto
Aplicação desenvolvida em Python para gerenciamento de cadastro de clientes via terminal. O sistema permite cadastrar novos registros, listar dados cadastrados e realizar buscas por e-mail com validação para evitar duplicidades.

## Tecnologias e Conceitos Aplicados
- **Linguagem**: Python 3
- **Estruturas de Dados**: Listas e Dicionários
- **Lógica e Algoritmos**: Modularização com funções, tratamento de strings e estruturas de controle (`while`, `if/else`, `for`)

## Como Executar
1. Certifique-se de ter o Python instalado.
2. Baixe o arquivo `cadastro_clientes.py`.
3. Execute o script no terminal ou VS Code com o comando:
   ```bash
   python cadastro_clientes.py
